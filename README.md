# RyotaQC V5 Online - Production

<div align="center">

**Aplikasi Quality Control untuk teknisi perbaikan & refurbish laptop Windows.**

Versi: **5.0.1** · Self-contained EXE (tidak butuh .NET terinstall)

</div>

## Cara Pakai

1. Download repo ini (Production branch)
2. Buka folder
3. Double-click RyotaQC.App.exe
3. Aplikasi terbuka langsung - siap dipakai

## Update

Aplikasi otomatis cek update saat dibuka. Jika ada versi baru:
- Popup "Update Wajib" muncul
- Klik "Update Sekarang"
- Tunggu download & restart otomatis

User **wajib** update - tidak bisa menutup popup sampai selesai.
Versi ditampilkan di menu utama aplikasi.
